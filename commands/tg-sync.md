description: Get the newest messages from Telegram into Telegram Assistant
argument-hint: [chat name]
---

Use the telegram skill. Run `tgkit sync` (add the chat name if given:
$ARGUMENTS). Report in one or two plain sentences how many new messages
arrived and whether any chat could not be updated. If it says to run
`tgkit setup`, ask the user to do that themselves; never run it for them.
